# open-convert 
                                                                                                                                                
  open-convert 是一个多格式文件转换平台，当前实现了文档转换子模块 doc-convert/，预留了 audio-convert/ 和 video-convert/。

### 粘贴文本转 Word / PDF

上传框下方的“粘贴文本”会读取剪贴板内容并打开可编辑文本框。点击“下一步”后可选择输出 Word（DOCX）或 PDF。

文本按 UTF-8 传输；Word 输出使用原生 OMML 数学公式，PDF 由同一份 DOCX 经 LibreOffice 生成，因此公式不会被转成图片或乱码。数学公式建议使用 LaTeX/Markdown 写法，例如：

```text
计算 $x^2 + \dfrac{1}{2}$

$$\begin{align*}
y^2&=x^2+1\\
z&=\sqrt{y}
\end{align*}$$
```

文本转换默认限制为 10MB；PDF 输出需要部署环境安装 LibreOffice（项目 Dockerfile 已包含）。
